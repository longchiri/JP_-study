# 🇯🇵 일본 여행 일본어 마스터

일본 전역에서 쓰는 일본어 학습 웹앱(후쿠오카 명물 포함). 메뉴 한자·히라가나·카타카나 읽기 + 구매/이동/숙소/관광 등 상황별 회화를 한 페이지에 담았습니다. 휴대폰 브라우저에서 바로 열리고, 글자·문장을 탭하면 일본어 발음이 나옵니다.

## 들어있는 내용

- **50음** — 히라가나·카타카나 전체 + 탁음/반탁음
- **메뉴** — **294개** 14개 카테고리: 후쿠오카·전국명물·라멘/면·덮밥/정식·고기/튀김·야키니쿠·스시/해산물·이자카야·중화·양식·밥/반찬·디저트·음료·조미료 (한자/가나/발음/뜻 + CC 사진/아이콘). 스시 네타 39·이자카야 35·라멘토핑·우동소바·야키니쿠 부위·중화·양식 포함. 카테고리 필터 + **검색**(한국어·발음·한자) 제공
- **상황** — **34개 시나리오** 7개 카테고리: 🍽️식당(입장·식권기·주문·라멘옵션·결제·스시야·예약 등), 🛒쇼핑(편의점·카페·면세·슈퍼·기념품·옷), 🚃이동(공항입국·택시·전철/IC카드·버스·길묻기), 🏨숙소(체크인·요청·체크아웃), 🗺️관광(안내소·입장권·사진부탁), 🆘긴급(약국·병원·분실), 🙏기본(인사·자기소개·되묻기)
- **숫자** — 숫자·개수 세기·금액(円)
- **퀴즈** — 가나/메뉴뜻/숫자 읽기 연습

> 📷 메뉴 사진은 음식 아이콘으로 표시했어요(오프라인·모바일에서 100% 작동, 저작권 문제 없음).

> 💡 발음은 휴대폰·브라우저의 음성합성 기능을 씁니다. 첫 화면 우측 상단 "🔇 소리 켜기"를 한 번 눌러주세요. (일본어 음성이 깔린 아이폰/안드로이드에서 가장 잘 들립니다.)
